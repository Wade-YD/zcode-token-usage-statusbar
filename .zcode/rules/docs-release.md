# 文档与发布

## 版本号（两处必须同步）

- `plugin/.zcode-plugin/plugin.json` → `version`
- `marketplace.json` → `plugins[0].version`

改了插件壳行为（钩子、自举、重启提醒）就升 minor；纯修复升 patch。

## README 双语

- `README.md`（英文，主）与 `README.zh-CN.md`（中文）是同源翻译：**改一边必须改另一边**。
- 功能/安装步骤/限制条件的表述必须一致，不得只更新其中一边。

## 文档写什么

- 写机制与判定条件（"什么时候会提醒重启""失败后多久重试"），不写易变事实
  （提交号、用例数、日期、星数）。
- 安全边界要写清楚：出网域名、只读数据库、凭据不落盘、asar 会被修改。

## 发布物料

- 发布资产（zip、宣传图、截图原图）不入仓库版本库；仓库只留源码与文档。
- 截图里不得出现真实 API Key、公司名、手机号、会话标题等个人信息。
